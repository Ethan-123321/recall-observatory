# 召回观察

面向消费者的缺陷产品召回公告检索、条件核验与交互可视化课程项目。

## 运行

安装 Python 3 后，在项目目录运行：

```sh
python server.py
```

打开 http://127.0.0.1:8767/ 。前端使用 Vue 3 与 ECharts，后端使用 Python 标准库。当前数据包含2023—2025年1303份一般消费品与汽车公告，保留官方来源与处理记录；样本不代表全国全量。

## 功能

- 公告检索、年份与风险筛选、图表联动。
- 型号、日期与批次条件组比对、原文依据及不确定性提示。
- 语音输入、自然语言筛选、月份追问、纠错和撤销。

## API 配置

运行后在“语音与证据助手”的“API配置与连接测试”中填写自己的密钥。配置仅保存在本机 `.qwen-config.json`，不会随本仓库发布。也可参考 `.env.example` 创建本机 `.env`。没有密钥时可使用检索、可视化和本地规则功能，云端语音及文本接口需单独配置。

切勿将真实密钥写进前端、README、截图或提交记录。不要强制添加被忽略的配置文件。本项目默认仅监听本机地址，上传源码不等于部署网站，不应直接作为公开云端服务运行。

## 数据与处理

`dataset/` 保留采集脚本、来源记录、处理产物与规则评估材料；`dist/` 包含网页及发布数据。来源公告中的企业联系方式属于公告证据，不是项目作者的个人信息。历史数据处理材料可能包含旧统计范围，当前页面以正式发布数据为准。产品核验不替代官方确认，汽车须通过官方渠道核实VIN。
