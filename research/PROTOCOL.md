# 交互任务对比实验执行协议

版本：recall-interaction-v1。任务及答案绑定 `tasks.json` 的公告版本。

## 研究问题与条件

研究问题是：与手动筛选相比，语音和图表联动能否帮助用户完成公告检索、统计追问、复杂范围核验及纠错恢复任务。分别观察完成率、用时、误操作、澄清、求助、转写编辑、请求失败和主观费力程度，不预设语音一定更快。

采用同一参与者完成两个条件的设计。手动条件使用筛选控件、图表、列表和核验表单；语音图表条件使用同一平台，并可通过语音连续完成任务。接口故障时允许文字回退，回退保留在记录中，不能作为实际语音使用。

每个条件包含四类任务：组合筛选、最多月份查询、复杂条件组核验、纠错恢复。A/B是两套同类材料，不能直接声称难度完全相同；通过顺序平衡减轻材料和学习效应。

| 编号分组 | 第一组 | 第二组 |
| --- | --- | --- |
| P001、P005…… | 手动A | 语音图表B |
| P002、P006…… | 语音图表A | 手动B |
| P003、P007…… | 手动B | 语音图表A |
| P004、P008…… | 语音图表B | 手动A |

参与人数按实际安排记录。人数为4的倍数便于保持顺序平衡；本协议不把课程可执行的样本量当作统计功效证明。

## 开始前

1. 固定公告版本、浏览器、电脑、麦克风、网络、模型平台和模型ID。配置状态可通过API设置查看，记录时不复制密钥。
2. 用非正式任务演示筛选、图表点击、语音停止、编辑转写、撤销和补充型号。练习不写入正式任务记录。
3. 确认麦克风收音与实际接口正常。打开右下角“语音 / 智能探索”并开始录音，用户可朗读“只看2025年的玩具”，查看转写后再发送。
4. 参与者采用P001这类编号，不在记录文件中填写姓名。研究者保留必要的设备和测试环境记录。

## 每个任务

实验和报告不在消费者页面展示。研究者在平台外发放 `tasks.json` 的题目并记录过程；`dist/research*.js` 为原实验工作台的保留代码，当前平台不加载，也不会自动生成实验记录。

1. 使用P001这类编号，按上表条件顺序和 `tasks.json` 材料逐项执行。每项先读题，确认理解后由研究者开始计时。
2. 每项任务前重置查询状态；核验任务打开指定公告。手动条件约定不使用助手，两条件使用相同正式数据。
3. 月份任务记录全部并列月份；核验任务展开至少一项对应原文证据；恢复任务经历初始筛选、风险替换、恢复三个状态。
4. 研究者记录完成时刻、误操作、求助和费力程度。以 `records-template.json` 为结构，按分析程序的字段要求录入正式记录；只填写实际观察到的计数，不把缺失观测记成零。
5. 目标达成后停止计时，再询问1—7分费力程度。评分时间不计入任务用时。未完成任务也保留记录，最长任务时长须事先统一约定。
6. 正式记录保存到 `research/exports/`（默认不进入Git）。平台不再自动计时或采集实验事件；外部计时和观察方法需写入论文方法章节。

## 记录和分析口径

任务记录需包含分配条件、材料、任务类型、目标结果、用时和费力程度；误操作、求助、澄清、纠错、撤销、转写编辑及请求情况依据实际观察记录。原始录音和密钥不进入实验记录。纠错命令次数不等于ASR识别错误数，观察者误操作也不等于请求失败数，应分开解释。

主分析采用每位参与者、每个条件、每类任务的首次记录；重复记录保留但不择优。完成率包括未完成任务。成功任务用时先按参与者汇总；完整配对耗时差要求同一人在两个条件的四类任务均成功。报告样本数、失败数、完整配对数和文字回退数，不能只报告成功用时。

费力程度是单题自报：1完全不费力，7非常费力。本题不是NASA-TLX或其他标准量表，不能冒用标准量表名称。

## 生成报告与论文图

安装绘图依赖：`python -m pip install -r research/requirements.txt`。

将整理的记录文件保存到 `research/exports/records.json`，运行：

```text
python research/analyze.py research/exports/records.json --output research/results
```

生成 `summary.json`、`INTERACTION_REPORT.md`、`interaction-results.svg/png`。无绘图依赖时可加 `--no-plots`。没有真人数据时，空模板只生成待录入报告和空图，不产生效率改善结论。

## 最后核查

核对记录中的公告版本、参与人数、任务数量、条件顺序、失败和回退；挑选成功、歧义、失败恢复各一例，结合事件顺序说明。自动测试和固定合成音频的接口测试属于工程验证，不填入真人任务数据。
