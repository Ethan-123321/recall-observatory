# 2025年度数据复核版

复核日期：2026-10-22。342条栏目目录完成AI辅助逐条文本复核；不等同于人工专家认证。

## 产物与口径

- `annual-2025.json`：原始提取快照，保持不变。
- `annual-2025-reviewed.json`：342条目录及复核字段、原文缺失、异常、重复关系。
- `recalls-2025-reviewed.json` / CSV / `recalls-2025.sqlite3`：341份去重分析公告。仅合并同日同标题且核心字段相同的1条重复，不合并扩大召回等不同公告。
- `annual-review-decisions.txt`：按原始快照索引记录的逐条类别和风险判定；稳定ID及原文证据见 `review-ledger-2025.json`。
- `quality-report-2025.json`：分类、风险、原文缺失、厂家确认和重复处理统计。

## 完成与未知的区别

340份HTML正文已读取分类、风险、型号、日期和批次；2份图片公告已视觉转录。8条原公告未披露型号，保留空值；另1条写“请详附件”，保存页面无型号附件，保留附件缺失提示。35份范围条件需厂家确认，不参与自动实际产品命中判断；这不是跳过文本复核。批次代码长得像日期，不据此修正生产日期。全部批次仍受型号及生产期限制。源字段误填的两个产品名称保留原值，并按标题整理展示名。

21类产品按用途；17种风险按缺陷和可能后果多标签。未明确伤害不扩写成特定风险。风险标签不是缺陷原因，尚不能提供标准化原因排名。每条公告只计一次；多标签比例之和可能超过100%。数量仅按原文单位汇总，不把包、只、盒混加，缺单位不猜测。目录条数不是全国召回事件次数。

## 可复现

运行 `python complete-2025.py` 重建复核数据、CSV、SQLite和浏览器资源；运行 `python verify-reviewed-2025.py` 核对原文哈希、字段、重复、复杂范围及各端一致性。原211份历史样本另存，分析与助手统一切换到年度341份。
