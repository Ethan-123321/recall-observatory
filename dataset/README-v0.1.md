# 中国消费品召回公告数据集 · 第一批

采集整理日期：2026-10-16。版本：v0.1。

## 本批内容

- 54 份按来源网址去重的官方召回公告；**一行是一份公告，不是一个型号或一件产品**。
- 公告发布日期范围：2025-02-17 至 2025-06-05。部分公告包含多个产品或型号，保留原始对应描述，不自动拆分以免关联错位。
- 按规则初分 12 类：玩具 13、服饰鞋包 8、家用电器 7、照明电器 5、文具 4、防护消防用品 4、个护电器 3、婴童用品 3、电源电器 3、家具家居 2、食品接触用品 1、饰品 1。
- 此批独立于原样例的 6 份公告，尚未接入核验界面；不会用尚未人工复核的批次自动判断用户产品。

## 文件

| 文件 | 用途 |
| --- | --- |
| recalls.csv | Excel 可直接打开，UTF-8 BOM，单元格内保留原字段文字 |
| recalls.json | 程序使用，风险标签和质量标记为数组，缺失为 null |
| recalls.sqlite3 | 数据库，recalls 表内保留完整 record_json |
| quality-report.json | 去重数量、失败页面、缺失率、分类数量、质量问题 |
| review-overrides.json | 人工复核过的复杂数量及计算依据 |
| raw/list-*.txt | 当次检索返回的官方列表页文本 |
| raw/batch-*.txt | 当次检索返回的公告正文文本及来源信息 |
| build.py | 从保存的文本重新清洗、去重、构建三种格式，无网络请求 |
| verify.py | 数据约束、三格式一致性、证据哈希和人工数量校验 |

## 采集过程与来源边界

来源为国家市场监督管理总局缺陷产品召回技术中心“国内消费品召回公告”栏目，列表入口：

- https://www.samrdprc.org.cn/xfpzh/xfpzhgg/index_23.html
- https://www.samrdprc.org.cn/xfpzh/xfpzhgg/index_24.html
- https://www.samrdprc.org.cn/xfpzh/xfpzhgg/index_25.html
- https://www.samrdprc.org.cn/xfpzh/xfpzhgg/index_26.html

直接 HTTP 下载返回 403，因此改用网页检索工具可访问的官方页文本。**raw 内是工具返回的文本快照，不是原始 HTML，也不保证与采集日的实时页面完全一致**；检索工具的缓存日期可能不同，列表页会移动，因此不能把这四页说成连续、完整时间段。

共尝试 68 个列表链接：57 个取得可解析正文（其中 3 个为重复），形成 54 个唯一公告；11 次失败或正文不完整，记录在质量报告。失败不计为零召回。每行保存确切来源网址、发布日期、采集日期、文本快照文件及该公告文本的 SHA-256。

本批是可追溯的公开资料采集与整理，不能写成实地调查或全国全量数据。网站为官方来源，数据分类及标准化字段由项目自行处理，不代表官方分类。

## 字段字典

| 字段 | 含义 / 规则 |
| --- | --- |
| id / source_url / title | 来源文章标识、原文链接和标题 |
| published_date / retrieved_date | 原文发布时间 / 本次整理日期，不能互相替代 |
| producer / product_name / brand | 生产者、产品名称、品牌；品牌缺失不能用企业名冒充 |
| model_raw | 原型号规格描述；可能包含多个型号 |
| production_dates_raw / batch_raw | 原生产日期与批次文字；保留月份、间断日期及特殊批次表述 |
| quantity_raw / quantity / quantity_unit | 原数量文字 / 解析或人工求和的数值 / 原单位 |
| quantity_method / review_note | 数量处理方法及人工复核理由 |
| defect_raw / consequence_raw | 缺陷和可能后果，二者分别保存 |
| emergency_raw / remedy_raw | 应急处置与召回措施 |
| contact_raw / responsible_raw / schedule_raw | 公告提供的联系方式、责任机构和计划安排；不代表当前仍在办理 |
| description_raw / other_report_raw / other_info_raw | 页面其余文字信息；图片没有 OCR，纯图片字段可能为空 |
| category / category_method | 产品类别初标和规则版本 |
| risk_tags / risk_method | 从后果文字提取的多标签风险及规则版本；不是事故发生率或风险等级 |
| review_status / quality_flags | 全记录仍需逐条复核；部分数量已独立人工核对 |
| extract_file / extract_sha256 | 来源快照相对路径及该公告片段哈希 |

## 当前质量

54 份均提取到生产者、产品名称、型号、生产日期原文、缺陷、后果和处理措施。11 份品牌字段为空，2 份批次字段为空，20 份没有可提取的产品描述文字（可能为图片）。空值表示未提取到有效文本，不保证原文从未提供。

6 份复杂数量已经对照正文逐项计算，例如三款光疗灯为 222 + 35 + 360 = 617 台；带有型号功率的数字不能作为数量。7 份没有明确数量单位。**不能把盒、套、件、台等单位混合后称为产品总件数**，统计应分单位，或优先统计公告份数。

14 份后果描述未命中明确风险词，保留空风险标签与待复核标记；其余标签也是关键词初标，应复核上下文（例如灭火器失效与产品自身起火是不同情形）。多风险公告会命中多个标签，标签计数合计可能大于公告总数。

当前可用于：公告检索、字段完整度分析、初步类别统计、人工标注工作。

接入自动核验前仍需：对多个型号与日期/批次的对应关系人工拆分确认、规范化日期、核查扩展或修订召回公告。数据量扩大后再讨论跨年趋势与地区分布，当前不据此评价品牌安全性。

## 重建

在本项目环境使用 Python 3 标准库即可，无需第三方依赖：

```text
python dataset/build.py
python dataset/verify.py
```

后续采集按相同格式保留新文本快照，再重建数据；可通过 source_url 去重。人工修正进入 review-overrides.json，保留理由，避免直接改生成文件而丢失依据。
