# 2023—2025 多领域召回样本

2026-10-23构建：1109份去重公告。一般消费品722、汽车383、食品4。
按发布日期：2023年227、2024年421、2025年461。

## 来源和口径

- 召回中心消费品栏目遍历917条目录、汽车栏目388条；保留请求、分页和正文SHA256。
- 福建食品召回栏目首页的2025年PDF有限样本。4份扫描件逐字段视觉核对；另一份待转录，不参与分析。不代表福建完整年度，更不代表全国食品召回。
- 食品接触用品栏目另采267条，未作为食品计数，避免杯碗等重复混入。
- 200条正文/图片未能可靠结构化的记录列入excluded-multidomain.json，不计入1109。
- 1组同日同标题及核心字段相同的记录合并。扩大召回等不同公告仍分别计数，不声称全国事件去重。

## 整理状态

保留原341份2025年度AI辅助文本复核结果；新增764份采用明确的产品分类及缺陷风险词规则，4份食品使用PDF视觉转录。**不能将规则标注称为全部逐条语义复核完成**。每条保存处理状态、原文、标签规则或转录依据。
汽车车型与生产范围保留完整段落，不自动拆成VIN清单；多组数量不随意求和。日期缺失、附件未取得、跨型号对应关系未核实时，不自动判断产品是否命中。风险标签不是已发生事故或标准化原因排名。

## 重建与验证

使用Python运行 collect-multidomain.py consumer cars（需网络），collect-food.py（需pypdf和网络），build-multidomain.py，再运行verify-multidomain.py。food-transcriptions.json为已核对的扫描件关键字段证据，不是自动OCR输出；不覆盖原PDF。
JSON、CSV、SQLite和浏览器JS由同一构建脚本产生。年度2025专题继续使用原独立复核数据，主检索、图表和助手改用多领域数据。

新增数据尚未全部完成语义复核，不能宣称全国召回趋势、事故率或品牌安全排名。未来扩充优先处理排除清单、食品更多年份及规则标注复核。
